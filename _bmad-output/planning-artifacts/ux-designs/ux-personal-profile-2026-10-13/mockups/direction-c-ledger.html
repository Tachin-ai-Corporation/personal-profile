Design direction C of 3 · Personal Profile

Ledger

Every section is a plain, flat table, so a profile with ten phone numbers reads the same as one with two: columns line up and nothing reflows. Row actions stay out of the way until a row is hovered or focused, and a kebab menu on every row gives touch and keyboard users the same actions. It is the quietest and most spreadsheet-like option, with editing happening in place inside the table.

What changes at 390 px

  • The numbered index becomes a Jump to select with the same numbers and deep links.
  • Two-pair key/value tables fold into one Field / Value column.
  • Multi-column tables (Phone, Email) become stacked rows: number and status on line one, label and type on line two, kebab on the right. Hover actions are never needed on touch.
  • The Save all bar keeps its single line and docks to the bottom edge.
