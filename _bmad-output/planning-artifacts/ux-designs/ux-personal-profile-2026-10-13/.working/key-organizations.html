What changes at 390 px

  • The grid drops to one column below 640 px (4 / 3 / 2 / 1 at 1280 / 1024 / 640 px); cards keep full anatomy and the 248 px minimum height.
  • The tab strip scrolls horizontally; no section index on /account.
  • Search is full width. For internal users, "Create new organization" stacks below it (not shown: Daniel is not internal).
  • Enter portal navigates the same tab, with the leave guard if anything is dirty. The app is never framed, so there is no new-tab variant and "Return to 1health" always shows (PM11).
  • Below 400 px the app-bar page nav (Personal Profile · Account) wraps under the wordmark as a segmented control.
  • Type icons, the "+N" chip and the truncated name show their Tooltip on hover, focus or tap. Type labels follow the Organization Type map (Health Provider reads "Healthcare").
  • The Info popover opens on hover, focus or tap, below the (i); it closes on Escape, blur or outside tap and returns focus to (i).
  • Pagination stays centered under the grid, 44 px items.
